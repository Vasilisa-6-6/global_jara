# Глобальное потепление
>В сайте ты становишься решателем проблем, появляются проблемы которые могут привести к глобальному потеплению и ты должен выбрать что ты сделаешь

>Каждое решение влеяет ны будущее и будущие решения!

>Появляется понимание о глобальной проблеме

>Ты сам пытаешься предотвратить появление глобального потепления

## Пример
Проблема: 

**Нужна древесина:**

- Вырубать леса
- Вырубать леса и садить деревья
- Заранее садить деревья, а потом вырубать леса
- Заменить древесину пластииком
- Забить на потребность жителей
